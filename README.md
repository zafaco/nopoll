# nopoll #

Fork of [nopoll](https://github.com/ASPLes/nopoll/tree/master) websocket library. The repository is used by the service [breitbandmessung.de](https://breitbandmessung.de) of the German Federal Network Agency (Bundesnetzagentur).

### Build dependencies ###
* Linux
* make
* libssl-dev
* libtool
* automake

### Building ###

1. Run `autogen.sh`
2. Run `make`
3. Run `make install`
